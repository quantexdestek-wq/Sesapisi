Quantex API Hakkında

Quantex API, Google Translate TTS teknolojisini kullanarak metinleri doğal ses ile okur. CORS dostu, hızlı ve ücretsizdir.

🚀 Hızlı Başlangıç

GET https://tts-api-production.up.railway.app/?text=Merhaba&lang=tr

📝 Parametreler

Parametre Tip Varsayılan Açıklama
text* string - Okutulacak metin
lang string auto Dil kodu (tr, en, es, vb.)
speed float 1 Hız (0.5 - 2)
pitch float 1 Ton (0.5 - 2)

💻 Örnek Kullanımlar

// JavaScript Fetch API fetch('https://tts-api-production.up.railway.app/?text=Hello&lang=en&speed=1&pitch=1') .then(response => response.blob()) .then(blob => { const audio = new Audio(URL.createObjectURL(blob)); audio.play(); });
# Python ile Kullanım import requests response = requests.get( 'https://tts-api-production.up.railway.app/', params={'text': 'Merhaba Dünya', 'lang': 'tr'} ) with open('audio.mp3', 'wb') as f: f.write(response.content)
